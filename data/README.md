# Data Preparation

## Text Data
We use the Tiny Shakespeare dataset for training and testing our models. 
```bash
wget https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt
```

## Image Data
We use the built-in MNIST, Fashion-MNIST, SVHN, and CIFAR-10 datasets from the `torchvision` library.
